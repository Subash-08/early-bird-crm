# Combined Phase 1–5 acceptance checklist

Use the existing detailed guides; this file is the overview. Previous checklists are preserved.

- [ ] Phase 1: Owner assigns enquiry; Sales receives it, records call, reschedules follow-up, sees correct tasks. Test import preview and duplicate review.
- [ ] Phase 2: Sales requests quote; Owner prepares/approves; PDF matches approved version; Sales shares and records acceptance of the exact option.
- [ ] Phase 3: Create booking once; partial advance does not release Operations; Owner verifies sufficient advance; invoice/receipt and booking balance agree.
- [ ] Phase 4: Arrange services; assign available driver/vehicle; prevent overlap; driver sees only permitted details; readiness and incidents govern trip completion.
- [ ] Phase 5: Sales requests supplier bill/payment; Owner approves; cancellation requires customer decision; refunds and supplier recovery remain independent; closure waits for reconciliation.
- [ ] Check cash collection, payment verification and physical cash handover separately.
- [ ] Check permissions through direct URLs/API requests, not just hidden navigation.
- [ ] Check phone layout, offline feedback and in-app updates.
- [ ] Check customer-facing documents for private supplier/margin/identity leaks.
- [ ] Review feature-coverage-audit.md: reports, remaining imports, Cloudinary media, PWA installation/push and production launch still need work.

Detailed guides: `phase-1-manual-test.md`, `phase-2-manual-test.md`, `phase-3-manual-test.md`, `phase-4-manual-test.md`, `phase-5-manual-test.md`.

Test record: date, role, booking/enquiry, steps, expected result, actual result, Pass/Fail/Not tested. Only mark business acceptance after the agency has performed the scenario.
